TableSelection

final class TableSelection (View source)

Which tables a dump skips, dumps structure-only, or dumps at all.

Built from the comma-separated --skip-tables-list, --structure-tables-list and --tables-list options, whose entries may contain * wildcards, and the list of tables that exist. Only existing tables are kept. When --tables-list is given it wins over the other two, as in Drush.
