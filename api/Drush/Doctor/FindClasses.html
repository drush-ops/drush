static array findClasses(string $namespace)

Finds instantiable #[AsCommand] classes in a Drush namespace.

The namespace is mapped onto Drush's src/ directory, so only Drush's own files are searched, never other packages sharing the namespace.

Parameters

string $namespace

A fully-qualified namespace below Drush\, e.g. Drush\Commands\user.

Return Value

array

The discovered class names, sorted.
