protected void attachConsoleLogger(ContainerInterface $container, OutputInterface $output)

Sends Drupal log messages to the console.

dr does this once per command through ConsoleSubscriber, but a container rebuild replaces logger.console with an instance that has no console logger attached, so it is done again after every rebuild. It also lets kernel tests see the log output.
