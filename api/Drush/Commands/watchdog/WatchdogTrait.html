trait WatchdogTrait (View source)

Helpers shared by the watchdog commands.

Classes using this trait inject Connection as $this->connection and ModuleHandlerInterface as $this->moduleHandler. Those that format records also inject EntityTypeManagerInterface as $this->entityTypeManager.
