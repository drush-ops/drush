The flags that shape a dump command.

Mysql

MySQL and MariaDB. Core's driver name is 'mysql' for both; the MariaDB client is used only when no mysql client is installed, since either speaks to both servers.

Pgsql

PostgreSQL. psql and pg_dump take no password on the command line; they read PGPASSWORD, which environment() provides to the processes the commands run. The connect string users paste relies on PGPASSFILE or ~/.pgpass instead.

Sqlite

SQLite. The database is a file, so there are no credentials, and a dump is .dump of that file. Table selection does not apply to the dump.

TableSelection

Which tables a dump skips, dumps structure-only, or dumps at all.
