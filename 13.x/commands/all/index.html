All commands¶

Tip

Press the / key to Search for a command. Or use your browser's Find in Page feature.

General

Command Description Aliases
archive:dump Backup your code, files, and database into a single file. ard
browse Display a link to a given path or open link in a browser.
completion Dump the shell completion script
content:export Exports content entities in YAML format.
drupal:directory Return the filesystem path for modules/themes and other key folders. dd, drupal-directory
generate Generate boilerplate code for modules/plugins/services etc. gen
help Display usage details for a command.
jn:get Execute a JSONAPI request.
list List available commands.
mk:docs Build a Markdown document for each available Drush command/generator.
recipe:apply Applies a recipe to a site. recipe
runserver Runs PHP's built-in http server for development. rs, serve
version Show Drush version.
workspace:publish Publish a workspace.

cache

Command Description Aliases
cache:clear Clear a specific cache, or all Drupal caches. cc, cache-clear
cache:get Fetch a cached object and display it. cg, cache-get
cache:rebuild Rebuild all caches. cr, rebuild, cache-rebuild
cache:set Cache an object expressed in JSON or var_export() format. cs, cache-set
cache:tags Invalidate by cache tags. ct
cache:warm Pre-warm all caches. warm, cache-warm

config

Command Description Aliases
config:delete Delete a configuration key, or a whole object(s). cdel, config-delete
config:edit Open a config file in a text editor. Edits are imported after closing editor. cedit, config-edit
config:export Export Drupal configuration to a directory. cex, config-export
config:get Display a config value, or a whole configuration object. cget, config-get
config:import Import config from the config directory. cim, config-import
config:pull Export and transfer config from one environment to another. cpull, config-pull
config:set Save a config value directly. Does not perform a config import. cset, config-set
config:status Display status of configuration (differences between the filesystem and database). cst, config-status

core

Command Description Aliases
core:cron Run all cron hooks in all active modules for specified site. cron, core-cron
core:edit Edit drush.yml, site alias, and Drupal settings.php files. conf, config, core-edit
core:requirements Information about things that may be wrong in your Drupal installation. status-report, rq, core-requirements
core:route View information about all routes or one route. route
core:rsync Rsync Drupal code or files to/from another server using ssh. rsync, core-rsync
core:status An overview of the environment - Drush and Drupal. status, st, core-status
core:topic Read detailed documentation on a given topic. topic, core-topic

deploy

Command Description Aliases
deploy Run several commands after performing a code deployment.
deploy:hook Run pending deploy update hooks.
deploy:hook-status Prints information about pending deploy update hooks.
deploy:mark-complete Mark all deploy hooks as having run.

entity

Command Description Aliases
entity:create Create a content entity after prompting for field values. econ, entity-create
entity:delete Delete content entities. edel, entity-delete
entity:save Re-save entities, and publish/unpublish is specified. esav, entity-save

field

Command Description Aliases
field:base-info List all base fields of an entity type field-base-info, fbi
field:base-override-create Create a new base field override bfoc
field:create Create a new field field-create, fc
field:delete Delete a field field-delete, fd
field:formatters Lists field formatters.
field:info List all configurable fields of an entity bundle field-info, fi
field:types Lists field types.
field:widgets Lists field widgets.

image

Command Description Aliases
image:derive Create an image derivative. id, image-derive
image:flush Flush all derived images for a given style. if, image-flush

locale

Command Description Aliases
locale:check Checks for available translation updates. locale-check
locale:clear-status Clears the translation status. locale-clear-status
locale:export Exports to a gettext translation file. locale-export
locale:import Imports from a gettext translation file. locale-import
locale:import-all Imports multiple translation files from the defined directory. locale-import-all, locale:import:all
locale:update Imports the available translation updates. locale-update

maint

Command Description Aliases
maint:get Get maintenance mode. Returns 1 if enabled, 0 if not. mget
maint:set Set maintenance mode. mset
maint:status Fail if maintenance mode is enabled. mstatus

migrate

Command Description Aliases
migrate:fields-source List the fields available for mapping in a source. mfs, migrate-fields-source
migrate:import Perform one or more migration processes. mim, migrate-import
migrate:messages View any messages associated with a migration. mmsg, migrate-messages
migrate:reset-status Reset an active migration's status to idle. mrs, migrate-reset-status
migrate:rollback Rollback one or more migrations. mr, migrate-rollback
migrate:status List all migrations with current status. ms, migrate-status
migrate:stop Stop an active migration operation. mst, migrate-stop

php

Command Description Aliases
php:cli Open an interactive shell on a Drupal site. php, core:cli, core-cli
php:eval Evaluate arbitrary php code after bootstrapping Drupal (if available). eval, ev, php-eval
php:script Run php a script after a full Drupal bootstrap. scr, php-script

pm

Command Description Aliases
pm:install Enable one or more modules. in, install, pm-install, en, pm-enable, pm:enable
pm:list Show a list of available extensions (modules and themes). pml, pm-list
pm:uninstall Uninstall one or more modules and their dependent modules. un, pmu, pm-uninstall

queue

Command Description Aliases
queue:delete Delete all items in a specific queue. queue-delete
queue:list Returns a list of all defined queues. queue-list
queue:run Run a specific queue by name. queue-run

role

Command Description Aliases
role:create Create a new role. rcrt, role-create
role:delete Delete a role. rdel, role-delete
role:list Display roles and their permissions. rls, role-list
role:perm:add Grant specified permission(s) to a role. rap, role-add-perm
role:perm:remove Remove specified permission(s) from a role. rmp, role-remove-perm

site

Command Description Aliases
site:alias Show site alias details, or a list of available site aliases. sa
site:install Install Drupal along with modules/themes/configuration/profile. si, sin, site-install
site:set Set a site alias that will persist for the current session. use, site-set
site:ssh Connect to a webserver via SSH, and optionally run a shell command. ssh, site-ssh

sql

Command Description Aliases
sql:cli Open a SQL command-line interface using Drupal's credentials. sqlc, sql-cli
sql:connect A string for connecting to the DB. sql-connect
sql:create Create a database. sql-create
sql:drop Drop all tables in a given database. sql-drop
sql:dump Exports the Drupal DB as SQL using mysqldump or equivalent. sql-dump
sql:query Execute a query against a database. sqlq, sql-query
sql:sanitize Sanitize the database by removing or obfuscating user data. sqlsan, sql-sanitize
sql:sync Copy DB data from a source site to a target site. Transfers data via rsync. sql-sync

state

Command Description Aliases
state:delete Delete a state entry. sdel, state-delete
state:get Display a state value. sget, state-get
state:set Set a state value. sset, state-set

theme

Command Description Aliases
theme:dev Toggle Twig development and cache aggregation settings. thdev
theme:install Install one or more themes. thin, theme:enable, then, theme-enable
theme:uninstall Uninstall themes. theme:un, thun, theme-uninstall

twig

Command Description Aliases
twig:compile Compile all Twig template(s). twigc, twig-compile
twig:unused Find potentially unused Twig templates.

updatedb

Command Description Aliases
updatedb Apply any pending database updates. Automatically enables maintenance mode during the update. updb
updatedb:status List any pending database updates. updbst, updatedb-status

user

Command Description Aliases
user:block Block the specified user(s). ublk, user-block
user:cancel Block or delete user account(s) with the specified name(s). ucan, user-cancel
user:create Create a user account. ucrt, user-create
user:information Print information about the specified user(s). uinf, user-information
user:login Display a one time login link for user ID 1, or another user. uli, user-login
user:password Set the password for the user account with the specified name. upwd, user-password
user:role:add Add a role to the specified user accounts. urol, user-add-role
user:role:remove Remove a role from the specified user accounts. urrol, user-remove-role
user:unblock Unblock the specified user(s). uublk, user-unblock

views

Command Description Aliases
views:dev Set several Views settings to more developer-oriented values. vd, views-dev
views:disable Disable the specified views. vdis, views-disable
views:enable Enable the specified views. ven, views-enable
views:execute Execute a view and show a count of the results, or the rendered HTML. vex, views-execute
views:list Get a list of all views in the system. vl, views-list

watchdog

Command Description Aliases
watchdog:delete Delete watchdog log records. wd-del, wd-delete, wd, watchdog-delete
watchdog:list Interactively filter the watchdog message listing. wd-list,watchdog-list
watchdog:show Show watchdog messages. wd-show, ws, watchdog-show
watchdog:show-one Show one log record by ID. wd-one, watchdog-show-one
watchdog:tail Tail watchdog messages. wd-tail, wt, watchdog-tail

why

Command Description Aliases
why:config List all config entities depending on a given config entity wc
why:module List all objects (modules, configurations) depending on a given module wm

yaml

Command Description Aliases
yaml:get:value Get a value for a specific key in a YAML file. y:get:value
yaml:lint Validates that a given YAML file has valid syntax. y:lint
yaml:unset:key Unset a specific key in a YAML file. y:unset:key
yaml:update:key Update a specific key in a YAML file. y:update:key
yaml:update:value Update the value for a specific key in a YAML file. y:update:value
